📊 Dataset Used

Crop Recommendation Dataset

The Machine Learning model powering KrishiMitra was trained using the Crop Recommendation Dataset, which contains soil and weather information for multiple agricultural crops.

Dataset Overview

This dataset is commonly used for agricultural Machine Learning tasks. It contains environmental and soil parameters associated with 22 different crop varieties.

The dataset enables the model to learn relationships between soil nutrients, climate conditions and crop suitability.

Features Used

Nitrogen (N) Phosphorous (P) Potassium (K) Temperature Humidity pH Value Rainfall

Dataset Statistics

  • Total Features: 7
  • Target Variable: Crop Name
  • Number of Crop Classes: 22
  • Total Records: 2200
  • Balanced Dataset

Crops Covered

Rice, Maize, Chickpea, Kidney Beans, Pigeon Peas, Moth Beans, Mung Bean, Black Gram, Lentil, Pomegranate, Banana, Mango, Grapes, Watermelon, Muskmelon, Apple, Orange, Papaya, Coconut, Cotton, Jute and Coffee.
